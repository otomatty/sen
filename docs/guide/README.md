## 更新のルール

画面や操作を変えたら、同じ変更でこのガイドも直してください。

ボタンの名前、画面の名前、ショートカットは、アプリの表示と揃えてください。

`bun run assistant:check` が、ガイドに書かれていない画面を見つけます。問題があれば、一覧を出して終了コード 1 で止まります。

`bun run assistant:knowledge` は、同じ確認に加えて、AI に渡す知識を `.tmp/assistant-knowledge.md` に書き出します。
