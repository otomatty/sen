# 課題の作成と編集

## 課題を作る

どの画面でも、`C` で作成画面が開きます。

サイドバー上部の「新しい課題」でも開きます。

見出しは「新しい課題」です。親を指定しているときは「その課題のサブ課題」と出ます。

左上のチームの識別子を押すと、チームを変えられます。

チームを変えると、サイクルと親課題は外れます。ステータスは、移った先の同じ種類になります。

タイトルの欄は「課題のタイトル」です。

Enter で説明へ移ります。

説明の欄は「説明を追加…」です。

下のボタンで、その場でプロパティを付けられます。

ステータス、優先度、担当者、ラベル、プロジェクト、見積もり、期日、親課題です。

サイクルを使うチームでは、サイクルも出ます。

右下の「課題を作成」で作ります。ショートカットは ⌘Enter（Windows・Linux は Ctrl+Enter）です。

「続けて作成」をオンにすると、タイトルと説明だけ空になり、次の課題を続けて書けます。

閉じても下書きは残ります。閉じるボタンの説明は「閉じる（下書きは保存されます）」です。

下書きは、画面を読み込み直したり、アプリを閉じたりしても残ります。

グループ見出しの「＋」など、ステータスやプロジェクトが決まった場所から開いたときも、書きかけのタイトルと説明はそのまま引き継がれます。プロパティは、開いた場所のものが付きます。

下書きはアカウントごとに分かれます。アカウントを切り替えても消えず、元のアカウントに戻ると続きを書けます。

課題を作るか、そのアカウントからログアウトすると、下書きは消えます。

タイトルが空のときは「タイトルを入力してください」と出ます。

作ったあとは、課題 ID と「を作成しました」と出ます。例：DEF-12 を作成しました。

「表示」を押すと、その課題を開けます。

作った人は、その課題の通知を自動で購読します。担当者を付けたときも、その人が購読に入ります。

## プロパティ

詳細画面の右側に、プロパティが並びます。クリックしてその場で変えられます。

- ステータス。チームのワークフローから選びます。
- 優先度。優先度なし、緊急、高、中、低です。`P` を押したあと、数字でも選べます。1 が緊急、2 が高、3 が中、4 が低、0 が優先度なしです。
- 担当者。空のときは「未割り当て」です。「担当者なし」も選べます。`A` で変更、`I` で自分に割り当てます。
- ラベル。空のときは「ラベルを追加」です。`L` で変更します。
- プロジェクト。空のときは「プロジェクトに追加」です。`Shift+P` です。ワークスペースのどのプロジェクトでも選べます。
- サイクル。サイクルを使うチームだけに出ます。空のときは「サイクルに追加」です。`Shift+C` です。入れるのは、その課題のチームのサイクルだけです。
- 見積もり。0、1、2、3、5、8 ポイントです。空のときは「見積もりなし」です。`Shift+E` です。
- 期日。空のときは「期日を設定」です。`Shift+D` です。
- 親課題。空のときは「親課題を設定」です。チームをまたいで選べます。自分自身や、自分の子孫は選べません。「親課題を解除」で外せます。
- チーム。別のチームへ移すときも、ここから選べます。

下には、作成者、作成、更新、完了の時刻が出ます。

一覧で課題を選んでいるときは、同じキーでまとめて変えられます。

## 詳細画面

課題の行を押すか、Enter で詳細が開きます。

タイトルはその場で直せます。Enter で確定し、Esc で書きかけを捨てます。

説明は、入力が止まると自動で保存されます。

説明の欄には「説明を追加…（Markdown 記法が使えます）」と出ます。

`J` で次の課題、`K` で前の課題です。Esc で一覧に戻ります。

右上に、購読のベル、「リンクをコピー」、「その他の操作」があります。

その他の操作は、ID をコピー、リンクをコピー、別のチームに移動、関係を追加…、削除です。

削除済みの課題では、削除の代わりに「復元」が出ます。

## Markdown

課題の説明、プロジェクトの説明、コメントは、GitHub と同じ Markdown で書きます。

エディタは、Markdown を直接読み書きします。

開いただけ、クリックしただけでは保存しません。

ショートカットは、⌘B で太字、⌘I で斜体、⌘E でインラインコードです。Windows・Linux では ⌘ が Ctrl です。

書ける記法と、入れ方は次のとおりです。

| 記法 | 入れ方 |
| --- | --- |
| 見出し（h1〜h6） | `# ` から `###### ` |
| 箇条書き | `- ` |
| 番号付き | `1. ` |
| チェックリスト | `[] ` |
| コード | ```` ``` ```` で囲む |
| 引用 | `> ` |
| リンク | `[表示](https://…)` |
| 太字 | `**文字**` |
| 斜体 | `*文字*` |
| 取り消し線 | `~~文字~~` |
| 水平線 | `---` |
| 表 | \| 見出し1 \| 見出し2 \| と書いて Enter |
| 画像 | `![説明](https://…)` |
| 注記 | 引用（`> `）の最初の行に `[!NOTE]`・`[!TIP]`・`[!IMPORTANT]`・`[!WARNING]`・`[!CAUTION]` と書いてスペース |
| 脚注 | `[^1]` で参照します。定義は、段落の先頭に `[^1]: ` と書きます |

下線は、Markdown に書き方が無いので使えません。

### 表

カーソルが表の中にあるとき、表の上に操作バーが出ます。行と列の追加と削除、列の寄せ、表の削除ができます。

Tab で次のセルへ移ります。見出しの行は削除できません。

### 画像

画像に使えるのは、http か https の URL だけです。画像のファイルは、貼り付けもドラッグもアップロードもできません。

画像は、見る人のブラウザが直接読み込みます。リファラーは送りません。

### 注記

| 記法 | 表示 |
| --- | --- |
| `[!NOTE]` | 「メモ」 |
| `[!TIP]` | 「ヒント」 |
| `[!IMPORTANT]` | 「重要」 |
| `[!WARNING]` | 「警告」 |
| `[!CAUTION]` | 「注意」 |

### 脚注

脚注の定義は、書いた場所に表示します。

### 改行

改行は、GitHub の Issue やコメントと同じです。1 回の改行が、そのまま改行になります。

### HTML

`<details>`、`<!-- コメント -->`、`<br>`、`<kbd>` などは、書いたまま保存します。HTML としては表示しません。実行もしません。

ソースとして見せます。「HTML」の印が付きます。

### 貼り付け

文字だけを貼り付けると、Markdown として読み込みます。Web ページなどからコピーした書式付きの文字は、書式を保って貼り付けます。

### 文字数の上限

課題のタイトルは 256 文字までです。説明とコメントは 65,536 文字までです。上限は GitHub と同じか、少し厳しめです。

### 保存したときの書き方

Sen のエディタで編集して保存すると、最初の 1 回だけ書き方が整えられます。表のセルの幅をそろえたり、改行に空白 2 個を付けたりします。GitHub での表示は同じです。

2 回目以降は、変えたところ以外は変わりません。

## サブ課題

大きな仕事は、サブ課題に分けられます。

「サブ課題を追加」を押します。欄は「サブ課題のタイトル（Enter で追加、Esc で閉じる）」です。

サブ課題は、親と同じチーム・プロジェクト・サイクルで作られます。

見出しの「サブ課題」の横に、完了件数と全件が出ます。

サブ課題を開いて、さらにサブ課題を足すこともできます。自分の子孫を親にはできません。

一覧では、表示設定の「サブ課題を表示」で、子を出すか隠せます。

## 課題どうしの関係

「関係を追加」から、次を指定します。

- 先に終わらせる課題を指定。`M` のあと `B`。選んだ課題が終わるまで、この課題は進められません。
- この課題を待つ課題を指定。`M` のあと `X`。この課題が終わるまで、選んだ課題は進められません。
- 関連する課題を指定。`M` のあと `R`。
- 重複としてマーク。`M` のあと `M`。この課題を、相手の重複にします。

メニューでは、操作の下に補足が出ます。

「先に終わらせる課題を指定」の補足は「この課題をブロックしている課題」です。

「この課題を待つ課題を指定」の補足は「この課題がブロックしている課題」です。

先に終わらせる課題を選ぶ画面では、左の見出しは「先に終わらせる（選ぶ課題）」です。

右の見出しは「待つ（この課題）」です。

検索欄は「先に終わらせる課題を検索...」です。

この課題を待つ課題を選ぶ画面では、左の見出しは「先に終わらせる（この課題）」です。

右の見出しは「待つ（選ぶ課題）」です。

検索欄は「この課題を待つ課題を検索...」です。

まだ選んでいない側は「未選択」です。

まだ選んでいないときは「課題を選ぶと、ここに結果が表示されます」です。

課題を選ぶと、下に結果が出ます。

先に終わる課題が完了でもキャンセルでもなければ、その課題が終わるまで、待つ課題は進められません。例：DEF-1 が終わるまで、DEF-2 は進められません。

先に終わる課題が完了かキャンセルなら、もう止めません。例：DEF-1 はもう終わっているので、DEF-2 を止めません。

例の DEF-1 は先に終わる課題です。DEF-2 は待つ課題です。

詳細の「関係」には、先に終わらせる課題、この課題を待っている課題、関連、重複元、重複と出ます。

「先に終わらせる課題」のうしろの補足は「この課題をブロックしている」です。

「この課題を待っている課題」のうしろの補足は「この課題がブロックしている」です。

まだ終わっていないブロックがあると、「未解決のブロック N件」と出ます。

一覧とボードでは、未完了の課題に止められている課題に印が付きます。

重複としてマークした課題は、完了でもキャンセルでもなければ、ステータスが「重複」になります。「重複」が無いときは、キャンセルの先頭のステータスに移ります。

相手の課題からも、同じ関係をたどれます。

コマンドパレットでは、親課題の設定の直後に、これらの操作が並びます。課題を選んでいるときだけです。

## コメントとメンション

「アクティビティ」に、変更の履歴とコメントが時系列で出ます。

コメント欄は「コメントを書く…（@ でメンバーをメンション）」です。

`@` のあとに名前を入れると、メンバーの候補が出ます。

Enter か Tab で挿入します。

送信は ⌘Enter（Windows・Linux は Ctrl+Enter）です。欄の下に「⌘ + Enter で送信」と出ます。

メンションされた人には、受信トレイへ通知が届きます。

自分のコメントは、メニューから「編集」と「削除」ができます。編集すると「（編集済み）」と付きます。

コメントした人は、その課題を自動で購読します。

## 購読

作成した課題、担当になった課題、コメントした課題は、自動で購読されます。

購読中の課題にコメントが付くと、受信トレイに届きます。ステータスが変わったときも届きます。

自分の操作は、自分には通知されません。

ベルのボタンで切り替えます。購読中は「通知の購読を解除」、外れているときは「通知を購読」です。

アクティビティの右には「通知を受け取る」と「通知をオフにする」もあります。

コマンドパレットの「通知の購読を切り替え」は、課題を 1 件だけ選んでいるときに出ます。

## 削除と復元

削除した課題は、一覧から消えます。データは「削除した課題」に残ります。

詳細の「削除」、または課題を選んで ⌘Backspace（Windows・Linux は Ctrl+Backspace）です。

削除した直後の表示に「元に戻す」が出ます。

設定の「削除した課題」でも「元に戻す」ができます。

削除済みの詳細を開くと「削除済み」と出ます。その他の操作の「復元」でも戻せます。

## 別のチームへの移動

「別のチームに移動…」で移します。詳細のプロパティ「チーム」からでも同じです。

移ると、ID の番号が振り直されます。例：DEF-12 が、移った先の次の番号になります。

ステータスは、移った先の同じ種類の先頭になります。

サイクルは外れます。

選んだ課題だけが移ります。サブ課題は、一緒に選ばない限り元のチームに残ります。

親課題は残ります。親はチームをまたげます。
