# 進捗

サイドバーの「進捗」です。`G` のあと `R` でも開けます。コマンドパレットの「進捗へ移動」でも開けます。

ワークスペースのプロジェクトを「活動」、課題を「タスク」として、進み具合を見ます。

右上に「自動で最新の状態に更新」と出ます。ほかの人が課題を変えると、開いている進捗もその場で変わります。

スプレッドシート連携が有効なときは「スプレッドシートを開く」も出ます。

数え方は、スプレッドシート連携と同じです。

## 何を数えるか

対象は、削除していない課題のうち、プロジェクトが付いていて、ステータスの種類がキャンセルでないものです。

初期状態の「キャンセル」と「重複」は、どちらも種類がキャンセルです。数えません。

プロジェクトが無い課題も、数えません。

プロジェクトを削除すると、課題からプロジェクトが外れるので、ここからも外れます。

保留は、種類がバックログの課題です。表示名を「保留」以外に変えても、種類がバックログなら保留です。

完了率は、対象が無いとき「タスクなし」です。

あるときは、種類が完了の件数を対象の件数で割り、小数点以下を切り捨てます。例：50%（1/2）。

保留は未完了として数えます。

直近期限は、保留でない未完了だけを見ます。種類が未着手と進行中です。

対象が無い、すべて完了、または未完了がすべて保留のときは「—」です。

保留でない未完了に期限が無いときは「期限未設定」です。

期限があるときは、いちばん早い完了予定を出します。例：2026/11/04。

期限の無いものが残っていれば、例：2026/11/04（未設定2件）のように足します。

活動状況は、次の順で最初に当てはまったものです。今日は日本時間です。期限が今日のものは、期限超過にしません。保留の期限は、期限超過の判定に使いません。

1. 対象のタスクが無いときは、タスク未登録。
2. 未完了が無いときは、完了。
3. 保留でない未完了に、期限が今日より前のものがあるときは、期限超過。
4. 未完了に保留があるときは、保留あり。
5. 未完了に進行中があるときは、進行中。レビュー中も、種類が進行中ならここです。
6. どれでもないときは、未着手。

工程は、`工程:` または `工程：` で始まるラベルです。接頭辞を除いた名前を、名前順に「／」でつなぎます。接頭辞のあとが空のラベルは使いません。

着手日は、その課題が初めて進行中、または完了になった日です。日本時間の日付です。

バックログや未着手に戻すと、今の着手時刻は消えます。履歴が残っていれば、進捗の着手日はその日のままです。

状態は、ステータスの表示名です。

完了日は、種類が完了のときだけ出ます。

優先度は、なし、緊急、高、中、低です。

## 活動一覧

タブの「活動一覧」です。開いた直後はここです。

上の数字は 4 つです。

- 活動。削除していないプロジェクトの数です。
- タスク。完了件数と対象件数です。キャンセルと重複は数えません。
- 期限超過。今日の日付も出ます。
- 保留あり。バックログの課題が残っている活動の数です。

状況のボタンで絞れます。すべて、期限超過、保留あり、進行中、未着手、完了、タスク未登録です。

表の列は、活動、直近期限、完了率、活動状況です。

活動の名前を押すと、そのプロジェクトが開きます。

プロジェクトが無いときは「プロジェクトはありません」です。

下に「数え方はスプレッドシートと同じです（キャンセル・重複は数えない、バックログは「保留」）。」と出ます。

## WBS

タブの「WBS」です。

活動ごとに、作業が並びます。活動の行は折りたためます。

列は、工程、作業、担当、着手日、完了予定、状態、完了日、優先度です。

並びは、完了予定が早い順です。画面には「まとめ方：活動 ・ 並び：完了予定が早い順」と出ます。

絞り込みは次です。

- 担当。すべて、自分、未割り当て、メンバーです。
- 工程。すべて、工程なし、付いている工程名です。
- 完了も表示。オフにすると、完了を隠します。
- 期限超過だけ。

行を押すと、その課題が開きます。画面の下にも「行を押すと課題を開きます。」と出ます。

## タイムライン

タブの「タイムライン」です。

活動ごとに、作業が横棒です。着手日から完了予定までを表します。

縮尺は、週、月、四半期です。ボタンのまとまりの名前は「縮尺」です。

「完了も表示」で、完了した作業を出せます。

日付が無い作業は「日付のない作業 N 件」と出て、WBS へ移れます。

名前を押すと、課題が開きます。
