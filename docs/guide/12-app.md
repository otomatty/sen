# アプリ・オフライン・同期

## インストール

Sen は、ブラウザにアプリとしてインストールできます。

デスクトップやホーム画面から、専用のウィンドウで開けます。

設定の「プロフィールと表示」の「アプリ」に、インストールがあります。

説明は「インストールすると、デスクトップやホーム画面から専用のウィンドウで開けます。一度開いた後は、オフラインでも起動します。」です。

このブラウザでインストールできるときは、「アプリをインストール」が出ます。

左下のユーザーメニューと、コマンドパレットにも、同じ項目が出ます。出るのは、インストールできるときだけです。

Chrome と Edge では、デスクトップと Android のどちらでも、上のボタンか、アドレスバーのインストールボタンから追加できます。

すでにアプリで開いているときは「インストールしたアプリで開いています」と出ます。

iPhone と iPad の Safari では、共有ボタンから「ホーム画面に追加」です。設定にも、その案内が出ます。

それ以外でボタンが出ないときは「ブラウザのアドレスバーやメニューにある「インストール」から追加できます」と出ます。

Mac の Safari では、ファイルメニューの「Dock に追加」です。

インストールしたアイコンを右クリック、または長押しすると、次を直接開けます。

- 新しい課題を作成
- 受信トレイ
- 自分の課題
- 検索

## 見た目

インストールしたアプリでは、タイトルバーやステータスバーが、テーマ（ライト、ダーク）の背景色に合います。

画面の切り欠きがあるスマートフォンでは、切り欠きを避けて表示します。

## オフライン

一度開いたあとは、オフラインでも、どの画面でも起動できます。

画面の移動は、ネットを優先します。オフラインのときや、応答に 3 秒以上かかるときは、保存してある版で開きます。

使い方動画、AI アシスタント、サーバーへの通信は、オフラインでは使えません。

オフライン中に変えた内容は、端末に残ります。左下の名前の下は「オフライン（N件を保持中）」です。

つながると、自動で送られます。

オフライン中は、ファイルを添付できません。

添付した画像も表示されず、ファイルも開けません。

## 更新

新しいバージョンがあると、「新しいバージョンがあります」と「更新」が出ます。

押すまでは、今の版のまま動きます。

設定の「アプリ」では「更新して再読み込み」です。コマンドパレットと、左下のユーザーメニューでは「新しいバージョンに更新」です。準備ができているときだけ出ます。

新しいバージョンがあるときは、左下のアバターの右上に点が付きます。

更新するときは、書きかけの保存と送信が終わるのを待ってから切り替えます。

書きかけのコメントがあると、捨ててよいか確認します。確認のタイトルは「書きかけのコメントがあります」です。

作成中の課題の下書きをこのブラウザに保存できなかったときも、確認します。このときのタイトルは「書きかけの内容があります」です。

すでに新しい版の画面を開いているときは、更新の案内は出ません。

## リアルタイム同期

変更は、手元の画面にすぐ出ます。サーバーへの送信は、その裏で行われます。

ほかの人の変更も、開いている画面に届きます。進捗の「自動で最新の状態に更新」も、この同期です。

左下の名前の下が「同期済み」で、変更が共有されているときは、リアルタイムで届いています。

リアルタイムの接続が無いときは、定期的に差分を取りにいきます。表示は、同じく「同期済み」です。

送信中は「同期中…」です。

送るのに失敗した変更は、元に戻して知らせます。

起動は、前回の内容を先に出して、差分だけを取ります。
