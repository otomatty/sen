# 検索・コマンドパレット・キーボード

## 検索

サイドバー上部の「検索」です。`/` でも、どの画面からでも開けます。

欄は「課題のタイトル・説明・ID（ENG-12）で検索…」です。

何も入れてないときは「課題を検索」と「タイトル・ID・説明から、入力したそばから絞り込みます。」です。

入力すると、その場で結果が絞られます。件数が欄の右に出ます。

タイトル、説明、ID を見ます。ひらがなとカタカナ、全角と半角の違いは吸収します。

タイトルが合うものを先に出します。最大 200 件です。

一致が無いときは「一致する課題はありません」です。

↓ または Enter で結果へ移り、もう一度 Enter で開きます。

Esc で、前の画面に戻ります。

削除した課題は、検索に出ません。

## コマンドパレット

⌘K（Windows・Linux は Ctrl+K）で開きます。

欄は「コマンドを入力するか、課題を検索…」です。

やりたいことを入れると、コマンドが絞られます。Enter で実行します。

課題のタイトルや ID を入れると、課題も候補に出ます。削除した課題は出ません。

課題をフォーカスまたは選択していると、その課題への操作が先に並びます。1 件のときだけ出る操作もあります。

チームごとのコマンドは、チームの数だけ並びます。例：そのチームの課題へ移動、バックログへ移動、サイクルへ移動、新しいサイクルの作成です。

移動、作成、表示の切り替え、テーマ、元に戻す、ログアウトもここからできます。

「アプリをインストール」は、このブラウザでインストールできるときだけ出ます。

「新しいバージョンに更新」は、新しい版の準備ができているときだけ出ます。

「AI アシスタントを開く」は、AI アシスタントが使えるときだけ出ます。

質問を入力すると、いちばん下に「AI に聞く：「入力した文字」」が出ます。選ぶとパネルが開き、その文字が質問として送られます。ほかに一致が無いときも、これで送信できます。使い方は、使い方動画と AI アシスタントのページにあります。

## キーボードショートカット

`?` で一覧が開きます。サイドバーの「ショートカット」でも開けます。

使い方動画のページの下にも、同じ一覧があります。

全体は、⌘K でコマンドパレット、`C` で課題の作成、`/` で検索、`?` で一覧、⌘Z で元に戻す、Esc で閉じるまたは選択の解除です。

移動は、`G` のあとに 1 文字です。

- `I` 受信トレイ
- `M` 自分の課題
- `E` チームのすべての課題
- `A` アクティブ
- `B` バックログ
- `C` サイクル
- `P` プロジェクト
- `R` 進捗
- `S` 設定
- `H` 使い方動画

`G` の移動は、今いるワークスペースの中です。

チームの課題、バックログ、サイクルは、チームの画面を開いているときはそのチームです。そうでないときは、チーム一覧の最初のチームです。

コマンドパレットの、チーム名が入った移動は、その名前のチームへ移ります。

一覧と課題の操作は、一覧とボードのページにあります。

Windows と Linux では、⌘ の代わりに Ctrl です。

## 元に戻す

⌘Z、またはコマンドパレットの「元に戻す」です。

課題の作成、プロパティの変更、削除、関係の追加を、直前から順に戻せます。

戻すと「元に戻しました」と、何を戻したかが出ます。

覚えていないときは「元に戻せる操作はありません」と出ます。

50 件まで覚えています。

説明文の自動保存、コメント、通知の購読の切り替えは、元に戻す対象になりません。

削除の直後に出る「元に戻す」は、その削除だけを戻します。
