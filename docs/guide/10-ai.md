# AI ツールとの連携

設定の「AI 連携」から、Claude、ChatGPT、Claude Code、Cursor などの AI ツールを Sen につなげます。

つなぎ方は MCP です。
AI ツールが、Sen の課題を読む・書くための接続です。

AI は、許可した人の権限で操作します。

行った変更には、「Claude 経由」のような印が付きます。
履歴、コメント、通知に残ります。
印の名前は、AI ツールが名乗る名前です。

ここでの AI は、課題の中身を扱います。使い方を質問する AI アシスタントとは別です。アシスタントは、課題の内容を送りません。

## つなぎ方

1. 設定の「AI 連携」を開きます。
2. 「接続先の URL」の「コピー」を押し、AI ツールに入れます。
3. AI ツールで接続を始めると、ブラウザで Sen の確認画面が開きます。
   ログインしていなければ、ログインのあとに開きます。
4. 「AI ツール」「戻り先」「アカウント」「ワークスペース」「できること」を確かめます。
   ワークスペースとできることを選んで、「許可する」を押します。
5. AI ツールに戻ります。

心当たりのない接続は、許可しないでください。
「キャンセル」で許可せずに戻れます。

「戻り先」は、許可したあとに戻る先です。
https のサイトはホスト名が出ます。
このパソコンのアプリに戻るループバックの URL は、「このパソコン（127.0.0.1）」のように出ます。
独自のスキームは、「スキーム名:// のアプリ」の形で出ます。

## ツールごとの手順

「AI ツール」で選ぶと、ツールごとの手順が出ます。
MCP の OAuth に対応したツールなら、接続先の URL を入れてつなげます。

### Claude

1. Claude（Web・デスクトップ・スマホのアプリ）で、カスタマイズ → コネクタ を開き、カスタムコネクタを追加します。
2. URL に、Sen の「接続先の URL」を入れて追加します。
3. Sen の画面が開いたら、ワークスペースとできることを選んで「許可する」を押します。

Team・Enterprise プランでは、組織のオーナーが組織の設定のコネクタから追加し、メンバーがそれぞれ接続します。

### ChatGPT

1. ChatGPT の設定で、カスタムの MCP サーバー（アプリ）を追加します。
2. サーバーの URL に Sen の「接続先の URL」を入れ、認証は OAuth を選びます。
3. Sen の画面が開いたら、ワークスペースとできることを選んで「許可する」を押します。

プランや組織の設定によっては、MCP サーバーを追加できないことがあります。

### Claude Code

ターミナルで次のコマンドを実行します。
`<URL>` は、Sen の「接続先の URL」に置き換えます。

```bash
claude mcp add --scope user --transport http sen <URL>
```

Claude Code で `/mcp` を開き、`sen` を選んで認証します。
ブラウザで Sen の画面が開きます。

### Cursor

「Cursor に追加」を押します。
うまく開かないときは、`~/.cursor/mcp.json` に画面の内容を追加します。

Cursor の MCP の設定で `sen` の接続を押すと、ブラウザで Sen の画面が開きます。

### VS Code

コマンドパレットで `MCP: Open User Configuration` を開き、画面の内容を追加します。

サーバーを起動すると、認証を求められます。
ブラウザで Sen の画面が開きます。

### その他

OAuth に対応した MCP クライアント（Streamable HTTP）に、Sen の「接続先の URL」を入れます。
接続を始めると、ブラウザで Sen の画面が開きます。
OAuth に対応していないツールは、下の「トークンで接続」を使います。

接続したら、AI ツールで話しかけます。
画面の「話しかけ方の例」は、押すとコピーできます。

例：Sen で、自分に割り当てられた課題を一覧にして。

## できること

確認画面の「できること」で選びます。
AI ツールが求めた範囲が、最初に選ばれています。

「課題の作成と変更」は、課題の作成・更新・コメントができます。
課題の削除はできません。

「閲覧のみ」は、課題を読むだけで、変更はしません。

| ツール | できること |
| --- | --- |
| `get_workspace` | チーム、ステータス、メンバー、ラベル、プロジェクト、今日の日付を取得します |
| `search_issues` | 課題を検索します |
| `get_issue` | 課題の説明、サブ課題、関係、コメントを取得します |
| `create_issues` | 課題をまとめて作成します。サブ課題も含められます |
| `update_issues` | 課題をまとめて更新します |
| `add_comment` | コメントを追加します |
| `link_issues` | 課題どうしを関係づけます |

閲覧でも、作成と変更でも、次が読めます。

- チーム、ステータス、メンバー、ラベル、プロジェクト、今日の日付。
- 条件に合う課題の検索。削除した課題は出ません。最初は、完了とキャンセルを除き、新しい更新から最大 50 件です。
- 課題 1 件の説明、サブ課題、関係、最新のコメント。

「課題の作成と変更」では、さらに次ができます。

- 課題をまとめて作る。1 回 50 件までです。サブ課題も一緒に作れます。サブ課題の中の、さらにサブ課題は、1 回の作成では作れません。
- 課題をまとめて更新する。1 回 50 件までです。別のチームへ移すと、課題の ID が変わります。
- コメントを書く。本文の `@名前` で、その人に通知します。
- 課題どうしを関係づける。ブロック、関連、重複です。重複にすると、完了でもキャンセルでもなければ「重複」のステータスに移ります。

名前が 1 件でも違うと、その回は何も作りません。更新も同じです。

課題の削除は、どの権限でもできません。

説明とコメントは、変換せずに Markdown のまま受け渡します。

タイトルは 256 文字、説明とコメントは 65,536 文字までです。

## 接続の管理

「接続中の AI ツール」に、OAuth の接続とトークンが並びます。
まだ無いときは「まだ AI ツールを接続していません。」です。

| 種類 | 各行に出るもの |
| --- | --- |
| OAuth の接続 | AI ツールの名前、できること、接続した日、最後に使ったとき |
| トークン | 名前、ツール名、できること、トークンの末尾、最後に使ったとき、期限 |

できることは「作成と変更」か「閲覧のみ」です。
まだ使っていないときは「まだ使われていません」と出ます。
トークンの名前とツール名が同じときは、ツール名を重ねて出しません。
期限が過ぎたトークンは「期限切れ」です。

使わなくなった接続は、ゴミ箱の「接続を解除する」を押します。
確認の見出しは「「Claude」の接続を解除しますか？」のように、AI ツールの名前が入ります。
説明は「この AI ツールは、Sen に接続できなくなります。使うときは、AI ツールから接続し直してください。」です。
「解除する」を押すと、「接続を解除しました」と出ます。

接続は、最後に使ってから 90 日たつと切れます。
そのときは、AI ツールから接続し直します。
AI ツールの中で接続し直すと、新しい行が増えます。
古い行は解除するか、使わなければ 90 日で消えます。

ワークスペースから外れると、その人の接続もトークンも使えなくなります。

## トークンで接続

OAuth に対応していないツールやスクリプトからは、トークンで接続します。
トークンは、接続先の URL と一緒にヘッダーに設定します。

1. 設定の「AI 連携」の「トークンで接続」を開きます。
2. 「できること」で「課題の作成と変更」か「閲覧のみ」を選びます。
3. 「有効期限」を選びます。
   30日、90日、1年、無期限です。
   最初は 90日です。
4. 「名前」は任意です。
5. 「トークンを発行」を押します。

発行すると「トークンを発行しました」と出ます。
「URL」「ヘッダー」「Claude Code の例」の 3 つが出ます。
使うツールに合わせて「コピー」を押し、設定します。

このトークンは今だけ表示されます。
設定が終わるまで、この画面を閉じないでください。
終わったら「完了」を押します。

コピーしていないと、「設定をコピーしましたか？」と聞かれます。
説明は「この画面を閉じると、トークンはもう表示できません。」です。
「閉じる」で閉じます。

使わなくなったら、「接続中の AI ツール」のゴミ箱の「トークンを無効にする」を押します。
確認の見出しは「「名前」のトークンを無効にしますか？」のように、トークンの名前が入ります。
説明は「このトークンを使っている AI ツールは、Sen に接続できなくなります。」です。
「無効にする」を押すと、「トークンを無効にしました」と出ます。
