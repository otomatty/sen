# AI ツールとの連携

設定の「AI 連携」から、Claude Code や Cursor などの AI ツールを Sen につなげます。

つなぎ方は MCP です。AI ツールが、Sen の課題を読む・書くための接続です。

AI は、発行した人の権限で操作します。

行った変更には、「Claude Code 経由」のような印が付きます。履歴、コメント、通知に残ります。

ここでの AI は、課題の中身を扱います。使い方を質問する AI アシスタントとは別です。アシスタントは、課題の内容を送りません。

## トークンを発行する

1. 設定の「AI 連携」を開きます。
2. 「AI ツール」で、Claude Code、Cursor、VS Code、その他を選びます。
3. 「できること」を選びます。
4. 「有効期限」を選びます。30日、90日、1年、無期限です。最初は 90日です。
5. 「名前」は任意です。例：仕事用の MacBook。
6. 「接続用のトークンを発行」を押します。

「課題の作成と変更」は、課題の作成・更新・コメントができます。課題の削除はできません。

「閲覧のみ」は、課題を読むだけで、変更はしません。

発行すると「トークンを発行しました」と出ます。トークンは、このときだけ表示されます。設定が終わるまで、画面を閉じないでください。

閉じるときにコピーしていないと、「設定をコピーしましたか？」と聞かれます。

## ツールごとの手順

Claude Code では、画面のコマンドをターミナルで実行します。ユーザー設定に追加するので、どのプロジェクトからでも使えます。

Cursor では、「Cursor に追加」を押します。開かないときは、`~/.cursor/mcp.json` に、画面の内容を追加します。

VS Code では、コマンドパレットで `MCP: Open User Configuration` を開き、画面の内容を追加します。

その他は、Streamable HTTP に対応した MCP クライアントに、画面の URL とヘッダーを設定します。

終わったら「完了」を押します。

AI ツールを開き直してから話しかけます。画面に、話しかけ方の例が出ます。押すとコピーできます。

例：Sen で、自分に割り当てられた課題を一覧にして。

## できること

| ツール | できること |
| --- | --- |
| `get_workspace` | チーム、ステータス、メンバー、ラベル、プロジェクト、今日の日付を取得します |
| `search_issues` | 課題を検索します |
| `get_issue` | 課題の説明、サブ課題、関係、コメントを取得します |
| `create_issues` | 課題をまとめて作成します。サブ課題も含められます |
| `update_issues` | 課題をまとめて更新します |
| `add_comment` | コメントを追加します |
| `link_issues` | 課題どうしを関係づけます |

閲覧でも、作成と変更でも、次が読めます。

- チーム、ステータス、メンバー、ラベル、プロジェクト、今日の日付。
- 条件に合う課題の検索。削除した課題は出ません。最初は、完了とキャンセルを除き、新しい更新から最大 50 件です。
- 課題 1 件の説明、サブ課題、関係、最新のコメント。

「課題の作成と変更」では、さらに次ができます。

- 課題をまとめて作る。1 回 50 件までです。サブ課題も一緒に作れます。サブ課題の中の、さらにサブ課題は、1 回の作成では作れません。
- 課題をまとめて更新する。1 回 50 件までです。別のチームへ移すと、課題の ID が変わります。
- コメントを書く。本文の `@名前` で、その人に通知します。
- 課題どうしを関係づける。ブロック、関連、重複です。重複にすると、完了でもキャンセルでもなければ「重複」のステータスに移ります。

名前が 1 件でも違うと、その回は何も作りません。更新も同じです。

課題の削除は、どの権限でもできません。

説明とコメントは、変換せずに Markdown のまま受け渡します。

タイトルは 256 文字、説明とコメントは 65,536 文字までです。

## トークンの管理

「接続中のトークン」に、発行済みが並びます。

まだ無いときは「まだ AI ツールを接続していません。」です。

各行に、名前、できること、末尾、最後に使ったとき、期限が出ます。

使わなくなったら、ゴミ箱の「トークンを無効にする」を押します。確認は「このトークンを使っている AI ツールは、Sen に接続できなくなります。」です。

無効にすると「トークンを無効にしました」と出ます。

ワークスペースから外れると、その人のトークンは使えなくなります。
