# プロジェクト

プロジェクトは、複数の課題にまたがる目標です。

進み具合は、紐づいた課題から自動で集計されます。

サイドバーの「プロジェクト」は、ワークスペースのすべてのプロジェクトです。`G` のあと `P` です。

チームの下の「プロジェクト」は、そのチームが選ばれているプロジェクトだけです。

## 一覧

タブは 3 つです。件数も出ます。

- 進行中。ステータスが進行中と一時停止です。
- 計画中。計画中とバックログです。
- 完了。完了とキャンセルです。

列は、名前、ステータス、リード、目標日、進捗です。

進捗は、キャンセルを除いた件数のうち、完了の割合です。

空のときは「プロジェクトはありません」です。タブだけが空のときは「進行中のプロジェクトはありません」のように出ます。ほかのタブに件数があると、そこへの案内が出ます。

「新しいプロジェクト」で作成画面が開きます。空のときのボタンは「プロジェクトを作成」です。

コマンドパレットの「新しいプロジェクトを作成」は、プロジェクトの一覧を開いて、同じ作成画面を出します。

## 新しいプロジェクト

見出しは「新しいプロジェクト」です。

名前の欄は「プロジェクト名」です。

説明の欄は「概要・目的を書く…」です。

ステータス、リード、目標日、色、チームを決めます。

ステータスは、バックログ、計画中、進行中、一時停止、完了、キャンセルです。最初は計画中です。

リードの最初は自分です。「なし」にもできます。

チームは、複数選べます。チームのプロジェクト画面から開くと、そのチームが最初から選ばれます。

「プロジェクトを作成」で作り、そのプロジェクトを開きます。「キャンセル」で閉じます。

## プロジェクトの中

タブは「概要」と「課題」です。

概要では、名前、色、ステータス、リード、開始、目標、説明を直せます。

説明の欄は「プロジェクトの概要・目的・成功の基準を書く…」です。入力が止まると保存されます。

「進捗」に、割合と内訳が出ます。スコープ、進行中、完了、未着手です。スコープは、キャンセルを除いた件数です。

グラフの凡例は、スコープ、進行中、完了、目安です。

「課題を追加」で、このプロジェクト付きの課題を作れます。

「課題一覧を見る」で、課題タブへ移ります。

課題タブは、このプロジェクトの課題だけの一覧です。リストとボードも使えます。

星のボタンでお気に入りにします。説明は「お気に入りに追加」と「お気に入りから外す」です。

お気に入りは、サイドバーの「お気に入り」に出ます。

その他の「プロジェクトを削除」で削除します。

確認は「課題は削除されず、プロジェクトとの紐づけだけが外れます。」です。

削除すると、進捗とスプレッドシートからも外れます。課題自体は残ります。
