# 受信トレイと自分の課題

## 受信トレイ

サイドバーの「受信トレイ」です。`G` のあと `I` でも開けます。

未読があると、サイドバーの名前の横に件数が付きます。

通知が届くのは、次のときです。

- 課題の担当者になったとき。
- コメントでメンションされたとき。
- 購読中の課題にコメントがついたとき。
- 購読中の課題のステータスが変わったとき。

自分の操作は、自分には届きません。

同じ課題の通知は、1 行にまとまります。件数が 2 件以上のときは、数字が付きます。

行を選ぶと、右にその課題が開きます。開くと既読になります。

広い画面では、最初の通知が自動で選ばれます。

空のときは「受信トレイは空です」と出ます。

メンバーが自分だけのときは、ほかの人の操作がないと通知が来ないと案内されます。「メンバーを招待」から、設定の全般へ移れます。

「自分の課題を見る」もあります。

右上のボタンは 2 つです。

- 「未読のみ」と「すべて表示」を切り替えます。未読が無いときは「未読の通知はありません」と「すべての通知を表示」です。
- 「すべて既読にする」です。

キーボードは、画面下の案内と同じです。

- `J` と `K` で移動します。
- Backspace で、その通知を削除します。Delete と `E` でも同じです。
- `U` で既読と未読を切り替えます。
- Enter で課題のページを開きます。

行のゴミ箱ボタンの名前は「通知を削除」です。課題そのものは消えません。

通知の削除は、⌘Z で戻せます。

## 自分の課題

サイドバーの「自分の課題」です。`G` のあと `M` でも開けます。

タブは 3 つです。

- 担当。自分が担当している課題です。開いた直後はここです。
- 作成。自分が作成した課題です。
- 購読中。通知を購読している課題です。

チームをまたいで並びます。

担当のタブで新しく作ると、担当者は自分になります。

完了した課題は、最初は過去 1 週間だけ出ます。「表示」の「完了した課題」で変えられます。

担当が無いときは「あなたに割り当てられた課題はありません」と出ます。作成と購読中で空のときは「課題はありません」です。

チームの一覧で `I` を押すと、その課題が自分の担当になり、担当のタブに加わります。
