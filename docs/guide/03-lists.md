# 一覧とボード

チームの課題は、サイドバーでチームを開き、「課題」から開きます。

タブは 3 つです。

- すべての課題。ステータスを問いません。`G` のあと `E` です。
- アクティブ。種類が未着手と進行中の課題です。レビュー中も入ります。`G` のあと `A` です。
- バックログ。種類がバックログの課題です。`G` のあと `B` です。

タブの無い URL を開くと、すべての課題と同じ一覧になります。

課題が無いときは「課題はありません」と「課題を作成」が出ます。

## リストとボード

右上のリストとボードのボタンで切り替えます。

ショートカットは ⌘B（Windows・Linux は Ctrl+B）です。

コマンドパレットの「リスト / ボード表示を切り替え」でも同じです。課題の一覧を開いているときに動きます。

リストは行の一覧です。

ボードは、グループごとの列にカードが並びます。ステータスでグループ分けしているときは、課題が無い列も出ます。

## ドラッグ＆ドロップ

カードや行を別のグループへドラッグすると、そのグループの値に変わります。

ステータスで分けているときは、列をまたぐとステータスが変わります。

進行中の種類にすると、着手した時刻が記録されます。

選んでいる課題をドラッグすると、選択中の課題も一緒に移ります。

同じグループの中で順番を変えるには、並び順を「手動」にします。

手動でないときに同じグループへドロップすると、「並び順を「手動」にすると、ドラッグで順番を入れ替えられます（表示 → 並び順）」と出ます。

グループが「ラベル」のときは、ドラッグでは移せません。

## グループ分けと並び順

「表示」を開きます。

グループは、ステータス、担当者、優先度、プロジェクト、サイクル、ラベル、なしです。

チームの課題一覧ではサイクルも選べます。自分の課題など、チームが決まっていない一覧ではサイクルの項目は出ません。

並び順は、優先度、手動、更新日、作成日、期日です。

最初は、グループがステータス、並び順が優先度です。

「完了した課題」は、すべて表示、過去1週間、過去1か月、表示しないです。

「サブ課題を表示」で、子を一覧に出すか選べます。

リストでは「空のグループを表示」もあります。

## 表示する項目

「表示」の「表示するプロパティ」で、行に出す項目を切り替えます。

ID、ステータス、優先度、ラベル、プロジェクト、サイクル、期日、見積もり、担当者、作成日です。

最初は、サイクルと見積もりがオフです。

## フィルター

「フィルター」を押すか、`F` です。

チームの課題では、ステータス、優先度、担当者、ラベル、プロジェクト、サイクル、作成者で絞れます。

チームをまたぐ一覧では、サイクルの代わりにチームで絞れます。

条件はチップで出ます。値を押すと変更できます。× でその条件を外します。ボタンの名前は「フィルターを削除」です。

「すべてクリア」で、条件を全部外します。

条件は重ねられます。同じ項目の中では、選んだ値のどれかに当てはまる課題が残ります。

一致するものが無いときは「条件に一致する課題はありません」と「フィルターをクリア」が出ます。

フィルター、グループ、並び順、表示項目は、画面ごとに保存されます。次に開いてもそのままです。

## 複数選択

`X` で、フォーカスしている課題の選択を切り替えます。

`Shift+J` で下へ、`Shift+K` で上へ、選択を広げます。

⌘A（Windows・Linux は Ctrl+A）で、表示中の課題をすべて選びます。

Esc で選択を解除します。

選ぶと下に「N件を選択中」と出ます。

ステータス、優先度、担当者、ラベル、プロジェクトを、まとめて変えられます。削除もできます。

## キーボード

一覧にフォーカスがあるとき、次が使えます。

- `J` または ↓ で次の課題。`K` または ↑ で前の課題。
- Enter で課題を開きます。
- `X` で選択です。
- `S` ステータス、`P` 優先度、`A` 担当者、`I` 自分に割り当て、`L` ラベルです。
- `Shift+P` プロジェクト、`Shift+C` サイクル、`Shift+D` 期日、`Shift+E` 見積もりです。

入力欄にカーソルがあるときは、これらのキーは文字として入ります。

右クリックで、その課題の操作メニューも出ます。
