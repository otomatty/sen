# 設定

左上のワークスペース名を押し、「ワークスペースの設定」を選びます。`G` のあと `S` でも開けます。

「プロフィールと表示」と「AI 連携」は、左下のユーザーメニューの「個人設定」「AI 連携」からも開けます。

開いた直後は「全般」です。

左のメニューは 3 つに分かれます。

- アカウント。プロフィールと表示、AI 連携です。
- ワークスペース。全般、メンバー、ラベル、チーム、削除した課題です。
- チームの設定。チームの名前が並びます。

狭い画面では、項目を開くと「設定」でメニューに戻れます。

## プロフィールと表示

名前を変えられます。欄を離れると保存されます。

メールアドレスは表示されるだけです。ここでは変えられません。

「GitHub のユーザー名」で、自分のユーザー名を登録できます。説明は「自分のユーザー名だけを登録できます。小文字で保存します。本人確認は行いません。」で、詳しくは [GitHub 連携](14-github.md) にあります。

アバターの色を選べます。

テーマは、この端末だけの設定です。システム、ライト、ダークです。

コマンドパレットの「テーマ：ダーク」「テーマ：ライト」「テーマ：システムに合わせる」でも変えられます。

左下のユーザーメニューの「テーマ」でも変えられます。「システム」「ライト」「ダーク」から選びます。選んでも、メニューは閉じません。

参加しているワークスペースが 2 つ以上のとき、「最初に開くワークスペース」が出ます。

ワークスペースが 1 つだけのときは出ません。

説明は「アプリを開いたときやログインしたときに表示するワークスペースです。すべての端末で共通です。」です。

「ワークスペース」で選びます。

選択肢は、参加しているワークスペースの名前です。

選ばないときの項目は「最後に開いたワークスペース」です。

選んだ内容は、すべての端末で共通です。

アプリを開いたときと、ログインしたときに使います。

選んだワークスペースがあるときは、それを先に開きます。まだ参加しているときだけです。

次に、この端末で、そのアカウントが最後に開いたワークスペースを開きます。まだ参加しているときだけです。

最後に、最初に参加したワークスペースを開きます。

「アプリ」では、インストールと更新ができます。詳しくは、アプリのページです。

## 全般

ワークスペースの名前と URL です。

URL は表示されるだけです。変更できません。

名前を変えられるのは、管理者だけです。

「メンバーの招待と、利用できるドメインの設定は「メンバー」にあります。」と出ます。

「メンバーの設定」から、メンバーの画面を開けます。

Sen を運用する人が決めたワークスペースでは、同じ画面に「GitHub 連携」も出ます。説明は「チーム 1 つと GitHub のリポジトリ 1 つを対応させます。トークンの値はここには出ません。」で、詳しくは [GitHub 連携](14-github.md) にあります。

## メンバー

見出しは「メンバー」です。

説明は、ワークスペース名のあとに「に参加している人と、招待中の人です。」と続きます。

管理者だけ、「メンバーを招待」のボタンがあります。

管理者でない人には「メンバーの招待は管理者が行います。」と出ます。

並びは、招待中、メンバー、利用できるドメインの順です。

招待中は、管理者にだけ出ます。

無いときは出ません。

「メンバーを招待」で、招待のダイアログが開きます。

ワークスペース名のメニューの「メンバーを招待」と、受信トレイの「メンバーを招待」からも、このダイアログが開きます。

招待できるのは、管理者だけです。

ダイアログの見出しは「メンバーを招待」です。

説明は「招待した人は、そのメールアドレスの Google アカウントでログインすると参加できます。招待は 7 日間有効で、1 回だけ使えます。」です。

メールの送信が設定されていないときは「招待メールの送信が設定されていません。招待したあとに出るリンクを、本人に送ってください。」と出ます。

「メールアドレス」にアドレスを入れます。

空のときの例は「hanako@example.com, ichiro@example.com」です。

チップがあるときの例は「続けて入力」です。

区切ると、チップになります。

案内は「カンマ・スペース・改行で区切ると、まとめて入れられます（20 人まで）。」です。

入力が空のときに Backspace を押すと、最後のチップが消えます。

チップの「×」でも外せます。

問題のないチップは、ふつうの色です。

形式が正しくないときと、すでにメンバーのときは、赤です。

利用できるドメインではないときは、黄です。

招待中のときは、青です。

チップに「・招待中」が付きます。

形式が正しくないときは、アドレスのあとに「は、メールアドレスの形式が正しくありません。」と出ます。

すでにメンバーのときは、アドレスのあとに「は、すでにメンバーです。」と出ます。

利用できるドメインではないときは、アドレスのあとに「は、利用できるドメインのアドレスではありません。」と出ます。

招待中のときは、アドレスのあとに「は招待中です。新しいリンクで招待し直します。」と出ます。

20 人を超えると「一度に招待できるのは 20 人までです。」と出ます。

問題があるあいだは、「N 人を招待」を押せません。

問題は、形式が正しくないこと、すでにメンバーであること、利用できるドメインではないこと、20 人を超えることです。

アドレスが無いときも押せません。

招待中のアドレスだけでは、押せます。

「権限」で「メンバー」か「管理者」を選びます。

補足は「管理者は、メンバーの招待・権限の変更・利用できるドメインの設定もできます。」です。

ボタンは「N 人を招待」です。

処理中は「招待しています…」です。

処理中は、ダイアログを閉じられません。

「キャンセル」で閉じます。

招待すると、見出しは「N 人を招待しました」です。

全員にメールを送れたときは「メールが届かないときは、リンクをコピーして本人に送ってください。」と出ます。

1 人も送れていないときは「招待メールは送られていません。リンクをコピーして、本人に送ってください。」と出ます。

一部だけ送れたときは「一部の人には、招待メールを送れませんでした。「メールは送られていません」と出ている人には、リンクをコピーして送ってください。」と出ます。

各行に、メールアドレスとリンクが出ます。

送れた行は「メールを送りました」です。

送れていない行は「メールは送られていません：」のあとに、理由が続きます。

招待メールは、ワークスペースごと、招待した人ごとに、1 日 50 通までです。

上限を超えると、理由は「1日に送れる招待メールの上限（50通）に達しました。リンクをコピーして本人に送ってください」です。

上限を超えたときも、送信が設定されていないときも、リンクをコピーして本人に送れます。

送信が設定されていないときは、理由の代わりに「メンバー」か「管理者」が出ます。

「リンクをコピー」で、その人のリンクをコピーできます。

コピーすると「コピーしました」になります。

「リンクは、この画面を閉じると二度と表示されません。あとで必要になったら、招待中の一覧の「招待し直す」で新しいリンクを作れます。」と出ます。

「続けて招待」で、もう一度入力に戻ります。

「閉じる」で、ダイアログを閉じます。

見出しは「招待中（N件）」です。

各行には「期限切れ」「メールを送りました」「メール未送信」のどれかが付きます。

2 行目は、権限と、招待した人と、期限です。

招待した人が分かるときは、名前のあとに「さんが招待」と続きます。

分からないときは「招待した人は不明」です。

期限が残っているときは「あと N 日」です。

過ぎているときは「M月D日に期限切れ」です。

「招待し直す」で、新しいリンクを作ります。確認は「新しいリンクで招待し直しますか？」です。説明は「今のリンクは使えなくなります。」です。ボタンは「招待し直す」です。

招待し直すと、「新しいリンクで招待し直しました」のダイアログが開き、リンクが出ます。

リンクの出方は、招待した直後と同じです。

「取り消す」で、招待をやめます。確認の見出しは、メールアドレスのあとに「への招待を取り消しますか？」と続きます。説明は「この招待リンクは使えなくなります。」です。ボタンは「取り消す」です。

取り消すと「招待を取り消しました」と出ます。

見出しは「メンバー（N人）」です。

名前、メールアドレス、権限が出ます。自分の行には「（あなた）」が付きます。

権限は「管理者」と「メンバー」です。

管理者は、自分以外の権限を変えられます。メンバーを外すこともできます。

外すときの見出しは、その人の名前のあとに「さんをワークスペースから外しますか？」と続きます。説明は「担当している課題は「担当者なし」になります。」です。ボタンは「外す」です。

外すと、その人の AI 連携の接続もトークンも使えなくなります。

そのメールアドレス宛ての、まだ参加していない招待も取り消されます。

外した人の端末に残っている内容は、サーバーからは消せません。

見出しは「利用できるドメイン」です。

説明は「設定すると、ここにあるドメインのメールアドレスの人だけが、招待・参加・利用できます。空のときは制限しません。サブドメインは含みません（example.com を許可しても a.example.com は含まれません）。」です。

制限していないときは「制限していません」と出ます。

設定を変えられるのは、管理者だけです。

管理者は、ドメインを入れて「追加」します。欄の例は「example.com」です。

まだ保存していない追加には「（未保存）」が付きます。

変更があるときだけ、「まだ保存していない変更があります」と「元に戻す」と「保存」が出ます。

「保存」で確定します。保存中は「保存しています…」です。

自分のドメインを含めずに保存しようとすると、「あなたのメールアドレスのドメイン（」で始まり「）を含めてください」で終わる文が出ます。

保存すると使えなくなる人がいるときは、確認が出ます。見出しは「次の人はこのワークスペースを使えなくなります」です。説明には「許可外のドメイン宛ての招待中の招待も取り消されます。」とあります。ボタンは「保存する」です。

使えなくなった人には「許可外のドメイン（利用できません）」と出ます。

許可外になった人は、そのワークスペースの画面、同期、AI 連携を使えません。

メンバーの記録は残ります。ドメインを許可に戻すと、再び使えます。

利用できるドメインが設定されているときは「利用できるドメイン：」のあとに、ドメインが並びます。

## ラベル

課題の分類に使うラベルです。ワークスペース全体で共通です。

色と「新しいラベル名」を入れて「追加」します。

名前と色は、あとから変えられます。

各行に、付いている課題の件数が「N件の課題」と出ます。

削除すると、付いていた課題からも外れます。確認は「このラベルが付いた課題からも外れます。」です。

工程として進捗に出したいラベルは、名前を `工程:` で始めます。例：工程:企画・設計。

## チーム

チームの一覧と、新しいチームの作成です。

説明は「チームごとに課題・ワークフロー・サイクルを持てます。」です。

名前の欄は「チーム名（例：デザイン）」です。

識別子の欄は「識別子（例：DES）」です。

識別子は、英大文字で始まる 1〜7 文字の英数字です。課題 ID の頭になります。

「チームを作成」で作ります。管理者でなくても、メンバーなら作れます。

作ったチームには、7 つのステータスが入ります。番号は 1 から始まります。

行を押すと、そのチームの設定が開きます。左の「チームの設定」から選んでも同じです。

## チームの設定

名前、識別子、色を変えられます。

識別子のヒントは「課題 ID の接頭辞（例：ENG-12）」です。

識別子を変えると、そのチームの課題 ID の頭も変わります。番号はそのままです。

「サイクル」で、「サイクルを使う」を切り替えます。

期間は、1週間、2週間、3週間、4週間です。

「ワークフロー」は、課題がたどるステータスです。種類ごとに並びます。種類は、バックログ、未着手、進行中、完了、キャンセルです。

名前と色を変えられます。

種類を選んで「新しいステータス名」を入れ、「追加」できます。

削除すると、同じ種類の別のステータスへ課題が移ります。その種類の最後の 1 つは削除できません。「この種類の最後のステータスは削除できません」と出ます。

## 削除した課題

削除した課題が、新しい順に並びます。

無いときは「削除した課題はありません。」です。

各行の「元に戻す」で、一覧に戻します。
