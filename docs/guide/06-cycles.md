# サイクル

サイクルは、チームの中の期間です。計画と振り返りの区切りに使います。

サイドバーでチームを開き、「サイクル」を選びます。`G` のあと `C` です。

サイクルを使わないチームでは、サイドバーに「サイクル」は出ません。

## 一覧

使っていないときは「サイクルは無効です」と出ます。「サイクルを有効にする」でオンになります。

オンのときは、右上に「新しいサイクル」があります。

今の期間が無いときは「進行中のサイクルはありません」と「サイクルを作成」です。

まだサイクルが無いときは、今週の月曜日から始まります。

すでにサイクルがあるときは、直前のサイクルの翌日から始まります。

長さは、チームの設定の週数です。1〜4 週間から選べます。

名前を付けないので、表示は「サイクル 1」のように番号です。

今のサイクルには「現在のサイクル」と出ます。期間と、残り日数も出ます。

数字は、完了（件数）、スコープ、進行中、ポイントです。

キャンセルと重複は、この件数に入りません。

グラフの凡例は、スコープ、進行中、完了、目安です。

「課題を見る」で、そのサイクルの課題一覧を開きます。

下には「今後のサイクル」と「過去のサイクル」が並びます。行を押すと、そのサイクルの課題です。

## 課題を入れる

課題は、自分のチームのサイクルにだけ入れられます。

一覧で `Shift+C`、または詳細の「サイクル」です。

コマンドパレットの「サイクルに追加…」でも同じです。課題を選んでいるときだけ出ます。

作成画面でも、サイクルを使うチームなら指定できます。

終わらなかった課題は、自動では次のサイクルに移りません。次のサイクルを選んで入れます。

コマンドパレットの「チーム名 に新しいサイクルを作成」は、そのチームにサイクルを作り、サイクルの画面を開きます。チームごとに 1 つ出ます。

期間を変える、サイクルをやめる、は設定のそのチームです。「サイクルを使う」と「期間」です。
